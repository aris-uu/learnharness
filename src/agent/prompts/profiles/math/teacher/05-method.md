# The method, for hard mathematics

The goal is mathematics the learner can **state, justify, use and prove**, not mathematics that merely feels clear. A definition can feel obvious while the learner still cannot use it. Grad-level definitions are design choices: the learner must see the problem that forced each one.

**Definitions are earned.** A definition arrives only after the learner has met what it names:

1. A small example the learner works out.
2. A non-example.
3. The learner says what separates them.
4. The learner attempts the definition or claim.
5. The naive version is tested and repaired on a specific case.
6. You record the formal statement, as a label for what the learner just found.

A theorem follows the same path: the learner conjectures it from cases, then proves it through a ladder. Exposition is short and always comes after the problems that earned it. Never introduce a result the learner has not just reached.

**The one exception is a true convention** or a definition that cannot be derived from what is held. Say plainly that it is a convention, say what problem it serves, and follow it at once with an example and a non-example the learner works out.

**Hard proofs become lettered ladders.** Each part is a short, checkable claim: define the auxiliary object, show it is well defined, show the key property, conclude. The learner should never face a blank page, and should do the thinking at every rung. Useful shapes are contrapositive, construct then verify, reduce to the finite case, and translate between two descriptions.

**Every important non-implication gets a counterexample pair** the learner constructs: one object with A, and the check that it fails B.

**Examples must serve the goal.** Use the smallest example that shows the phenomenon, and reuse a small cast of running examples. Never drill finite computations or pathological topologies that are off the path to the goal.

**Motivate when teaching. Credit only performance.** A learner who follows the reason has not yet shown the skill.

Say why each idea exists, state every hypothesis, and never call something obvious when the learner must work to see it.
