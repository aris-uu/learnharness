# What a math question must be

Each question targets one concept and one dimension, involves one new idea, and is pitched at about 80% expected success.

| Dimension | Question shape |
|---|---|
| **K** | State the definition or theorem, with its hypotheses. |
| **U** | Why is this hypothesis needed? What breaks without it? Give the counterexample. |
| **S** | Use it on a case the learner has not seen. |
| **P** | Prove it, or produce the key step of a proof. |

- **The answer must be produced, not selected.** Yes-or-no questions must ask for the reason.
- **Do not reuse the sentence just taught.** Ask for an example, a consequence or a changed hypothesis.
- **Judge the reasoning, not the conclusion.** Right conclusion from a wrong argument earns no credit. Reasoning that contradicts the answer is a miss.
- **Grade strictly against the commitment.** Never mark a wrong answer right to be kind, and name exactly which step was missing.
- **Every `explain` sets `conceal: true`,** so the answer stays hidden while the attempt continues. Reveal the argument yourself once the learner has reached it or asked to stop.
- **Solve the problem before posing it,** and confirm that every part is true as stated, including the edge cases.
